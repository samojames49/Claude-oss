# سلف‌ساز تلگرام (نسخهٔ پیشرفته، سبک Self VTR)

سرویس سه‌بخشی سلف‌بات تلگرام:

| فایل | نقش |
| --- | --- |
| [`bot.py`](bot.py) | ربات **سلف‌ساز/مدیریت**: لاگین کاربران، فروش اعتبار ساعتی (سکه)، اجرای یک پروسهٔ `self.py` برای هر مشتری، پنل ادمین، پرداخت. |
| [`self.py`](self.py) | خودِ **سلف‌بات** (اکانت کاربر با Pyrogram): تایم، قفل، پاسخ خودکار، دشمن، ریکشن، مدیریت گروه، دانلود و قابلیت‌های پیشرفته. |
| [`helper.py`](helper.py) | ربات **هلپر**: پنل تنظیمات به‌صورت inline که از طریق فایل‌های JSON به `self.py` دستور می‌دهد. |

ماژول‌های مشترک: [`config.py`](config.py) (تنظیمات از `.env`)، [`db.py`](db.py) (پایگاه‌دادهٔ JSON امن و اتمیک)، [`payments.py`](payments.py) (درگاه پرداخت)، [`compat.py`](compat.py) (سازگاری با Pyrogram استاندارد).

> ⚠️ **هشدار حقوقی/امنیتی:** خودکارسازی روی اکانت شخصی («سلف») ممکن است باعث محدود یا حذف‌شدن اکانت توسط تلگرام شود. مسئولیت استفاده بر عهدهٔ کاربر است.

## نصب

```bash
pip install -r requirements.txt
cp .env.example .env
# سپس مقادیر .env را کامل کنید
```

روی پایتون ۳٫۱۲ بستهٔ `tgcrypto` بیلد نمی‌شود؛ بدون آن هم کار می‌کند (فقط کندتر).

## پیکربندی

همهٔ کلیدها و توکن‌ها از فایل `.env` خوانده می‌شوند (دیگر داخل کد نیستند). حداقل موارد لازم:

- `API_ID` و `API_HASH` از [my.telegram.org](https://my.telegram.org)
- `BOT_TOKEN` (ربات سلف‌ساز) و `HELPER_BOT_TOKEN` (ربات هلپر) از [@BotFather](https://t.me/BotFather)
- `ADMIN_ID` آیدی عددی مالک

> 🔐 **مهم:** توکن‌ها و شماره کارتی که در نسخهٔ اولیه داخل کد بودند لو رفته‌اند. حتماً آن‌ها را در بات‌فادر/بانک باطل و جایگزین کنید.

## اجرا

فقط دو فایل را اجرا کنید (هلپر جداگانه):

```bash
python bot.py       # ربات سلف‌ساز (خودش self.py را برای هر کاربر اجرا می‌کند)
python helper.py    # ربات هلپر (پنل)
```

`self.py` را دستی اجرا نکنید؛ `bot.py` پس از لاگین موفق آن را با آرگومان‌های
`user_id phone API_ID API_HASH` اجرا می‌کند.

## قابلیت‌های پیشرفته (سبک Self VTR) که اضافه شد

- **ساعت در بایو** علاوه بر اسم: `بیو تایم روشن` / `بیو تایم خاموش`
- **ذخیرهٔ پیام‌های حذف‌شده:** `سیو حذفیات روشن` / `خاموش`
- **ذخیرهٔ پیام‌های ویرایش‌شده:** `سیو ادیت روشن` / `خاموش`
- **رصد کاربران** (تغییر اسم/یوزرنیم/بایو/عکس): روی پیام کاربر ریپلای و `رصد` / `حذف رصد` / `لیست رصد`
- **پروفایل خودکار:** `ست پروفایل اسم۱ | اسم۲ | اسم۳` سپس `پروفایل خودکار روشن` / `خاموش`
- **انقضا:** نمایش زمان باقی‌مانده با `انقضا`
- **درگاه پرداخت آنی ریالی** در ربات سلف‌ساز (با `PAYMENT_GATEWAY_ENABLED=true`) با شارژ خودکار سکه
- **گزارش سلامت ساعتی به ادمین** و **اجرای خودکار سلف‌های افتاده**
- **پیام همگانی** ادمین

این قابلیت‌ها از پنل هلپر هم قابل دسترسی‌اند: همهٔ دسترسی‌ها روی یک صفحه قرار دارند (بدون صفحه‌بندی و بدون زیرمنوی جدا).

## اصلاحات مهمِ پایداری/امنیت

- `self.py` دیگر کامپایل‌خطا ندارد (قبلاً با `IndentationError` اصلاً اجرا نمی‌شد).
- توقف سلف یک کاربر دیگر **همهٔ** سلف‌ها را نمی‌کشد (باگ `pkill -f self.py` رفع شد).
- پیام «سکه تمام شد» حالا واقعاً `await` و ارسال می‌شود.
- پس از ری‌استارت ربات مدیریت، سلف‌های زنده و تایمر شارژ ساعتی **بازیابی** می‌شوند.
- پایگاه‌دادهٔ JSON با **قفل و نوشتن اتمیک** (رفع خرابی/گم‌شدن تغییرات هم‌زمان).
- کسر سکه در شرط‌بندی و تایید پرداخت **اتمیک و ضدِ دوباره‌کلیک** شد.
- عضویت اجباری، وضعیت «ترک‌کرده» را هم درست تشخیص می‌دهد.
- هندلرهای تکراری در هر سه فایل حذف شدند.
- ارسال کد ورود به یک ربات خارجی ناشناس (نشت اطلاعات) حذف شد؛ فقط به Saved Messages خودتان می‌رود.
- درخواست‌های مسدودکنندهٔ `requests` در سلف به ترد جدا منتقل شدند.

## تست دستی (نیازمند توکن/اعتبار واقعی)

اجرای زندهٔ تلگرام به توکن و اکانت واقعی نیاز دارد که در این محیط موجود نیست.
پس از پر کردن `.env` این مسیرها را بررسی کنید:

1. **کامپایل و ایمپورت:** `python -m py_compile bot.py self.py helper.py`
2. **لاگین:** در ربات سلف‌ساز `/start` ← «فعالسازی» ← ارسال شماره ← کد ← (در صورت نیاز) رمز دو مرحله‌ای. باید `sessions/<user_id>.session` ساخته و `self.py` اجرا شود.
3. **پنل هلپر:** در چت هلپر هر متنی بفرستید یا اینلاین `@helperbot panel`؛ همهٔ قابلیت‌ها روی یک صفحه هستند و تاگل‌های پیشرفته را همان‌جا امتحان کنید.
4. **قابلیت‌های سلف:** در Saved Messages دستورها را بزنید: `پینگ`، `تایم روشن`، `بیو تایم روشن`، `سیو حذفیات روشن`، سپس از یک اکانت دیگر پیامی بفرستید و حذف/ادیت کنید.
5. **پرداخت:** با `PAYMENT_GATEWAY_ENABLED=false` مسیر کارت‌به‌کارت و رسید؛ با `true` مسیر درگاه و دکمهٔ «پرداخت کردم / بررسی».
6. **سلامت:** پنل ادمین ← «بررسی سلامت سلف‌ها» و «پیام همگانی».
