# 🎧 ربات پلیر تلگرام (پخش موزیک و ویدیو در ویس‌چت)

رباتی کامل و آماده برای پخش آهنگ و ویدیو داخل **ویس‌چت گروه‌های تلگرام** — شبیه
ربات‌های پلیر معروف (Rapid Player و مانند آن) با پنل دکمه‌ای، صف پخش، جستجوی
اینلاین، چند اسیستنت، پنل تنظیمات گروه و بخش مدیریت.

روی [Pyrogram (فورک kurigram)](https://github.com/KurimuzonAkuma/pyrogram) +
[PyTgCalls](https://github.com/pytgcalls/pytgcalls) + [yt-dlp](https://github.com/yt-dlp/yt-dlp)
نوشته شده و مستقل از بخش سلف‌ساز همین مخزن است.

---

## ✨ قابلیت‌ها

**پخش**

- پخش صوتی و ویدیویی در ویس‌چت گروه (`/play`، `/vplay`)
- پخش از یوتیوب (لینک، نام آهنگ، پلی‌لیست، شورتز، لایو)
- پخش لینک اسپاتیفای (نام قطعه گرفته و از یوتیوب پخش می‌شود)
- پخش هر لینکی که yt-dlp پشتیبانی می‌کند (ساندکلاد، اینستاگرام، …)
- پخش رادیو/لینک زندهٔ `m3u8`, `mpd` و فایل مستقیم (`/stream`)
- پخش فایل صوتی/ویدیویی که در خود تلگرام ریپلای شده
- دو حالت پخش: `direct` (استریم بدون دانلود) و `download` (اول دانلود، پایدارتر)
- انتخاب کیفیت صدا و تصویر از تنظیمات

**کنترل**

- توقف/ادامه، بعدی، پایان، بی‌صدا، صدا (۱ تا ۲۰۰)
- جابه‌جایی زمان (`/seek`, `/seekback`)، پخش از اول، سرعت پخش (`/speed 1.5`)
- تکرار آهنگ (`/loop`)، بُر زدن صف (`/shuffle`)
- پنل شیشه‌ای کامل زیر پیام «در حال پخش» + تصویر اختصاصی آهنگ
- صف پخش با نمایش، حذف تک‌آیتم و خالی‌کردن

**مدیریت**

- پنل `/settings` برای هر گروه: اجازهٔ پخش (همه/ادمین‌ها)، زبان (فارسی/انگلیسی)،
  خروج خودکار اسیستنت، روشن/خاموش کردن پیام «در حال پخش»
- دادن دسترسی کنترل به کاربر عادی (`/auth`, `/unauth`, `/authlist`)
- کش ادمین‌ها با `/reload`
- ورود/خروج دستی اسیستنت (`/userbotjoin`, `/userbotleave`)

**ویس‌چت پیشرفته**

- **پنل پلیر** (`پنل پلیر`): پنل دکمه‌ای همهٔ تنظیمات گروه در چهار بخش (پخش، آمار کال،
  امنیت کال، ظاهر) — با `فهرست پیوی` همان پنل در چت خصوصی مدیر باز می‌شود
- **آمار کال**: ثبت زمان حضور اعضا در ویس‌چت، آمار امروز/چند روز اخیر/روز هفته، ریست
  دستی و خودکار (روزانه/ماهیانه)، ارسال خودکار آمار پس از بسته‌شدن ویس‌چت، کارت کاربر
  با رتبه و زمان حضور (`آیدی`)
- **امنیت کال**: تشخیص و گزارش رفتار مشکوک (ورود متعدد، مایک باز هنگام ورود، ورود
  ویدیویی مکرر، منابع/خروجی‌های متعدد)، میوت خودکار ورودی‌ها با شرط قدمت عضویت و
  خلاصهٔ فایل‌شده در پایان کال
- **صندلی داغ**: بازی نوبتی ویس‌چت با صف مهمان‌ها، زمان‌سنج هر نوبت، میوت خودکار بقیه و
  پنل کنترل (`صندلی داغ`, `افزودن مهمان`, `مهمان بعدی`, `پایان صندلی داغ`)
- **پخش زندهٔ تلویزیون/ماهواره** با منوی دسته‌بندی‌شده و قابل ویرایش (`پخش زنده`)
- **زیرنویس فارسی (SoftSub)**: چسباندن فایل `srt`/`vtt`/`ass` روی پخش ویدیویی (`زیرنویس`)
- پخش در ویس‌چت کانال متصل به گروه (`تنظیم کانال پلیر` + `پخش کانال`)
- عنوان‌گذاری ویس‌چت (`تنظیم عنوان کال`) و دعوت اعضای اخیر/ویژه (`دعوت کال اخیر`,
  `دعوت کال ویژه`)
- پاک‌سازی خودکار پیام پایان پخش، حالت کلاسیک بدون تصویر و حذف پیام‌های سرویسی ویس‌چت

**ابزار**

- دانلود آهنگ و ویدیو به‌صورت فایل (`/song`, `/video`)
- جستجوی یوتیوب با انتخاب دکمه‌ای (`/search`)؛ هر نتیجه منوی کار دارد: پخش صوتی، پخش
  ویدیویی، دریافت فایل آهنگ یا ویدیو
- جستجوی ویژهٔ فیلم و سریال با پخش ویدیویی (`فیلم`, `سریال`)
- دانلود و پخش پایدار از یوتیوب/اینستاگرام/تیک‌تاک (`دانلود <لینک>`)
- پرش به زمان دقیق (`زمان پخش 01:20`) و صدای رسانه با فیلتر ffmpeg (`صدا رسانه 150`)
- **جستجوی اینلاین** (`@bot نام آهنگ`)
- متن آهنگ (`/lyrics`) از سرویس رایگان LRCLIB
- `/ping`, `/uptime`, `/stats`

**سودو**

- آمار کامل، فایل لاگ، پخش‌های فعال، پیام همگانی (`-pin`, `-user`, `-nogroup`)
- افزودن/حذف سودو، مسدودسازی کاربر و گروه، حالت تعمیرات، پاک‌سازی کش
- حالت خصوصی (`PRIVATE_MODE`) با تایید گروه‌ها توسط `/approve`

**پایداری**

- چند اسیستنت (`STRING_SESSION2`, `STRING_SESSION3`, …) و توزیع خودکار گروه‌ها بین آن‌ها
- خروج خودکار وقتی ویس‌چت خالی می‌شود یا پخش مدتی متوقف می‌ماند
- تشخیص بسته‌شدن ویس‌چت و پاک‌سازی وضعیت
- سقف مدت، سقف صف، سقف پخش ویدیویی هم‌زمان
- دیتابیس JSON با نوشتن اتمیک و ذخیرهٔ خودکار

## 🚀 نصب

### پیش‌نیازها

- پایتون ۳٫۱۰ یا بالاتر
- **ffmpeg** (الزامی)
- **deno** (پیشنهاد جدی) — نسخه‌های جدید yt-dlp برای یوتیوب به یک موتور جاوااسکریپت
  نیاز دارند؛ بدون آن بعضی فرمت‌ها استخراج نمی‌شوند.

```bash
sudo apt update && sudo apt install -y ffmpeg
curl -fsSL https://deno.land/install.sh | sudo DENO_INSTALL=/usr/local sh -s -- -y
```

### نصب پکیج‌ها

> ⚠️ این ربات به فورک `kurigram` نیاز دارد، در حالی که بخش سلف‌ساز مخزن از
> `pyrogram` رسمی استفاده می‌کند. هر دو یک ماژول `pyrogram` را نصب می‌کنند، پس
> **برای پلیر یک محیط مجازی جدا بسازید.**

```bash
python3 -m venv .venv-player
source .venv-player/bin/activate
pip install -r player/requirements.txt
```

### تنظیمات

```bash
cp player/.env.example player/.env
# مقادیر را پر کنید
```

حداقل موارد لازم: `API_ID`, `API_HASH`, `BOT_TOKEN`, `STRING_SESSION`.

- `API_ID` و `API_HASH` از [my.telegram.org](https://my.telegram.org)
- `BOT_TOKEN` از [@BotFather](https://t.me/BotFather) — در بات‌فادر **Inline Mode**
  را روشن کنید و **Group Privacy** را خاموش (`/setprivacy` → Disable) تا ربات
  دستورهای گروه را ببیند.
- `STRING_SESSION` نشست اکانت کاربری اسیستنت:

```bash
python -m player.tools.gen_session
```

### اجرا

```bash
python -m player
```

### داکر

```bash
cd player
cp .env.example .env   # مقادیر را پر کنید
docker compose up -d --build
docker compose logs -f
```

## 🎛 راه‌اندازی در گروه

1. ربات را به گروه اضافه و **ادمین** کنید (حق «دعوت کاربران» لازم است تا اسیستنت را
   وارد کند و حق «حذف پیام» برای تمیز نگه‌داشتن چت).
2. **ویس‌چت گروه را روشن کنید.**
3. بنویسید: `/play نام آهنگ` — اسیستنت خودش وارد گروه و ویس‌چت می‌شود.

اگر گروه خصوصی است و ربات نمی‌تواند لینک دعوت بسازد، اسیستنت را دستی به گروه اضافه
کنید یا `/userbotjoin` را بزنید.

## 📡 شخصی‌سازی شبکه‌های پخش زنده

فهرست شبکه‌ها در `player/data/live_channels.json` است و ساختار ساده‌ای دارد:

```json
{
  "categories": [
    {
      "id": "national",
      "title": "شبکه‌های سیما",
      "channels": [
        { "name": "شبکه ۱", "url": "https://example.com/tv1/index.m3u8", "video": true },
        { "name": "رادیو پیام", "url": "https://example.com/payam/index.m3u8", "video": false }
      ]
    }
  ]
}
```

با `video: false` شبکه فقط صوتی پخش می‌شود (مناسب رادیو). بعد از ویرایش فایل، در گروه
`/reloadlive` را بزنید تا بدون ری‌استارت خوانده شود.

## 🔥 صندلی داغ

1. ویس‌چت را روشن کنید و **اسیستنت را ادمین با دسترسی «مدیریت ویدیو چت»** کنید (بدون
   این دسترسی بازی فقط نوبت‌ها را اعلام می‌کند و مایک‌ها دست‌نخورده می‌مانند).
2. `صندلی داغ 3` — بازی با نوبت‌های سه دقیقه‌ای شروع می‌شود (ریپلای روی یک کاربر، او را
   اولین مهمان می‌کند).
3. `افزودن مهمان` (ریپلای) نفرات را به صف اضافه می‌کند و `حذف مهمان` آن‌ها را برمی‌دارد.
4. با پایان زمان هر نوبت، مایک مهمان بسته و نفر بعد اعلام می‌شود؛ دکمه‌های زیر پیام
   نوبت هم «مهمان بعدی»، «توقف/ادامهٔ نوبت» و «پایان بازی» را دارند.
5. با بسته‌شدن ویس‌چت، بازی خودکار تمام و مایک کسانی که ربات بسته بود باز می‌شود.

## 🧪 تست

تست‌های واحد (بدون نیاز به توکن و شبکه):

```bash
python -m unittest discover -s player/tests -t .
```

پوشش: قالب‌بندی زمان/حجم، صف پخش و تکرار، فیلتر دستورها (فارسی و انگلیسی)،
پایگاه‌داده و نوشتن اتمیک، همخوانی کلیدهای زبان‌ها، تشخیص لینک منابع، آمار کال،
امنیت کال، فهرست پخش زنده، بازی صندلی داغ، پارامترهای ffmpeg (سیک، سرعت، صدا و
زیرنویس)، بارگذاری هندلرها و اینکه هیچ دکمهٔ شیشه‌ای بی‌پاسخ (مرده) نمانده باشد.

تست دستی زنده به توکن واقعی نیاز دارد؛ مسیر پیشنهادی:

1. `/start` در خصوصی و `/help` و دکمه‌های راهنما
2. در گروه با ویس‌چت روشن: `/play` (لینک و نام)، سپس `/queue`, `/pause`, `/resume`,
   `/skip`, `/volume 120`, `/seek 30`, `/loop 2`, `/end`
3. `/vplay` برای ویدیو و ریپلای روی فایل صوتی + `/play`
4. `/settings` و `پنل پلیر` (تغییر زبان، اجازهٔ پخش، آمار و امنیت کال)
5. جستجوی اینلاین: `@YourBot نام آهنگ` و منوی کارهای `/search`
6. `آمار کال`، `آیدی`، `پخش زنده`، `صندلی داغ` + `افزودن مهمان` + `مهمان بعدی`
7. سودو: `/stats`, `/activevc`, `/logs`, `/broadcast تست`
